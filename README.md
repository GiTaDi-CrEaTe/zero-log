# 🛡️ ZERO-LOG // THREAT HUNTER
**Privacy-First, Client-Side AI Log Analysis Engine.**

Zero-Log is a high-performance security utility designed for SOC analysts who need to analyze sensitive server logs without compromising data privacy. 

### 🚀 Why Zero-Log?
Most log analyzers require you to upload your data to a third-party server. Zero-Log uses **100% Client-Side JavaScript** to parse and analyze your logs. **Your data never leaves your browser.**

### 🧠 Features
- **Heuristic Threat Detection:** Automatically flags Brute-Force and DDoS patterns.
- **UA Fingerprinting:** Detects automated tools like `curl`, `python-requests`, and `zgrab`.
- **Zero-Trust Architecture:** No database, no backend, no data collection.
- **Real-time Visualization:** Instant threat distribution charting.

### 🛠️ Tech Stack
- **Vite + React** (Frontend)
- **Tailwind CSS** (Hacker-Brutalist UI)
- **PapaParse** (High-speed in-browser CSV parsing)
- **Recharts** (Threat visualization)
